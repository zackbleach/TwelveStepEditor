Generator for the iOS app icon: 12 Step key layout on a blue gradient, plus dark and tinted variants.
Regenerate from the repo root with `swift Tools/app-icon/render-icon.swift TwelveStepEditor/Assets.xcassets/AppIcon.appiconset`.
It writes AppIcon.png, AppIcon-Dark.png and AppIcon-Tinted.png (1024x1024); Contents.json already references them.
